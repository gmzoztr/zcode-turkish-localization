# Katkıda Bulunma Rehberi (Contributing Guidelines)

ZCode Desktop Türkçe Yerelleştirme projesine hoş geldiniz! ZCode'un yapay zeka destekli kodlama yeteneklerini Türkiye'deki tüm yazılımcılar için eksiksiz ve en doğal Türkçe ile buluşturuyoruz.

---

## 🛠️ Nasıl Katkı Sağlayabilirsiniz?
1. **Eksik Çeviri veya Hata Bildirimi:**
   - GitHub üzerinde bir [Hata Bildirimi (Bug Report)](https://github.com/gmzoztr/zcode-turkish-localization/issues/new?template=bug_report.md) açın.
2. **Sözlük Geliştirmesi:**
   - `tr_dictionary_zcode.json` dosyası projenin ana sözlüğüdür (6.295+ anahtar). Önerilen çeviriler için PR gönderebilirsiniz.
